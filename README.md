## Project Overview

This project develops an AI-based system for detecting fraudulent credit card transactions. The system analyzes transaction-level information (amount, time, merchant category, customer profile and location) and flags transactions that are likely to be fraudulent.

The task is formulated as a **binary classification problem**:

- `0` (`is_fraud = 0`) — legitimate transaction
- `1` (`is_fraud = 1`) — fraudulent transaction

The main challenge is **extreme class imbalance**: fraud makes up well under 1% of all transactions, so accuracy alone is misleading. Evaluation focuses on precision, recall, F1 and PR-AUC.

## Data Processing Pipeline

1. **Load** raw train and test CSV files
2. **Clean:** parse timestamps and dates of birth, remove duplicate transactions, check missing values
3. **Engineer features** (below)
4. **Encode** merchant category using one-hot encoding fit on the training set only
5. **Save** processed datasets and EDA figures

### Engineered Features

| Feature | Description |
|---|---|
| `hour`, `day_of_week`, `month` | Time of the transaction |
| `is_weekend` | Weekend flag |
| `is_night` | Night flag (22:00 – 03:59) |
| `age` | Customer age at transaction time |
| `gender_male` | Binary gender flag |
| `log_amt` | log(1 + transaction amount) |
| `log_city_pop` | log(1 + city population) |
| `distance_km` | Haversine distance between customer home and merchant |
| `cat_*` | One-hot merchant category |

Identifiers (card number, names, street, transaction ID) are removed to avoid data leakage and privacy issues.

## Assumptions and Limitations

- Labels are assumed correct (generated by the simulator, not confirmed by real investigations).
- Fraud patterns are assumed broadly stable between the training and test periods.
- All features are available at transaction authorization time.
- Simulated data may not reflect adaptive real-world fraudster behavior.
- Limited diversity (about 1,000 simulated customers and 800 merchants, US only).
- Demographic fields (gender, age) may introduce fairness concerns.
